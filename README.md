# Ijwi

A talking avatar that speaks Kinyarwanda, English, Polish and more. Open the site, tap the mic, talk.

- Replies: Claude Haiku via the Anthropic API. The key is pasted into the page once and saved only in
  that browser; it is never stored in this repo.
- Kinyarwanda voice: C4IR (Hugging Face demo). Kinyarwanda speech-to-text: Pindo.
- English, Polish, etc.: the browser's own speech recognition and voices.

Static site, no build step. The full version (server, email alerts, daily summary) lives separately.
